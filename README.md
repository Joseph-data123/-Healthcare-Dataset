# Exploratory data analysis in Healthcare

## Executive Summary 
This project used SQL and Power Query to clean and analyze healthcare admission records, followed by an interactive Power BI dashboard. The analysis explored length of stay, billing, medical conditions and admission trends.

## Data Check summary 

I cleaned the healthcare dataset by removing duplicate records and rows with negative billing amounts. I also standardized the data by correcting formatting issues in the hospital column. Finally, I created a new Length of Stay column by calculating the number of days between each patient’s admission and discharge dates. The cleaned data was then used to create an interactive Power BI dashboard.

### My insights from analysis 
Exploratory data analysis is used to understand the data and identify possible patterns, trends or unusual values. It does not mean that a major problem must always be found. In this dataset, most results were evenly distributed, with only small differences between medical conditions, admission types and billing amounts. Therefore, the main focus of this project was improving data quality by removing duplicates, removing negative billing records, standardizing hospital names and creating a length-of-stay column. This ensured that the data was accurate and ready for visualization in Power BI.
